# Libero - Privacidade

## Camadas de Proteção

### 1. Hardware
- LED visível quando gravando
- Botão físico de mute
- Tampa de câmera

### 2. Captura
- VAD: só grava quando há voz
- Buffer circular: últimos 30s
- Zonas de exclusão: banheiro, quarto

### 3. Processamento
- Edge computing: processa localmente
- Extração de features: só o que importa
- Descarte do raw: áudio bruto descartado

### 4. Armazenamento
- Criptografia end-to-end
- Expiração automática
- Armazenamento local

### 5. Acesso
- Autenticação forte
- Papéis definidos
- Log de acesso
- Revogação

### 6. Interface
- Borrar nudez
- Borrar terceiros
- Resumo em vez de raw

### 7. Ética
- Dignidade
- Autonomia
- Transparência
